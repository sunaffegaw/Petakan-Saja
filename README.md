# PROSOCI - Petakan Saja

PROSOCI (Problem Solving Circle) merupakan wadah diskusi
bagi mahasiswa yang memiliki permasalahan dalam pembuatan
peta dan penggunaan QGIS.

## Isi Repository

- Data Pemetaan
- Tutorial QGIS
- Contoh Peta
- Studi Kasus

Repository ini menjadi prototipe awal untuk menguji kebutuhan
mahasiswa terhadap sumber data, tutorial, dan pemecahan masalah
pemetaan secara bersama.
